# Week 3 – Data Visualization and Reporting for Business Insights

## Overview
This week focuses on data visualization and reporting for the BizInsight-AI project.

## Objective
The objective is to convert cleaned business data into meaningful visualizations and insights.

## Work Completed
- Loaded the cleaned datasets prepared during Week 2.
- Used Pandas for data grouping and aggregation.
- Used NumPy for numerical analysis.
- Created Bar Charts for category and business comparisons.
- Created Line Charts for monthly trends.
- Created Scatter Plots to study relationships between variables.
- Created Histograms to understand data distributions.
- Created Pie Charts to show proportions and shares.
- Created Heatmaps for correlation analysis.
- Created Area Charts to represent trends and magnitude.
- Created Box Plots to analyze distributions and potential outliers.
- Used Matplotlib for standard visualizations.
- Used Seaborn for statistical visualizations.
- Used Plotly to create an interactive visualization.
- Analyzed product revenue and profit performance.
- Identified loss-making products.
- Analyzed customer spending and churn status.
- Analyzed inventory levels and low-stock products.
- Compared profit margins across product categories.
- Generated business insights from the visualizations.
- Developed practical business recommendations.
- Completed the Week 3 Data Visualization and Reporting task.
