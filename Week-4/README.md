# Week 4 – Predictive Modeling Using Regression

## Overview
This week focuses on predictive modeling using regression techniques for the BizInsight-AI project.

## Objective
The objective is to use historical business data to build and evaluate regression models for predictive business analysis.

## Work Completed
- Loaded cleaned sales data prepared during Week 2.
- Aggregated sales data at monthly level.
- Created time-based and previous-month business features.
- Selected relevant predictive features.
- Divided the data into training and testing datasets.
- Applied feature normalization using StandardScaler.
- Checked feature correlation for multicollinearity.
- Built a Linear Regression model using Scikit-learn.
- Generated monthly revenue predictions.
- Evaluated the model using RMSE and R² score.
- Applied 5-Fold Cross-Validation.
- Tested Polynomial Regression for model comparison.
- Performed actual vs predicted revenue analysis.
- Conducted prediction error analysis.
- Generated business interpretation and recommendations.

## Key Outcome
Linear Regression performed better than Polynomial Regression for the current dataset and feature set. The results indicate that additional business and historical features can be incorporated in future versions to improve forecasting performance.
